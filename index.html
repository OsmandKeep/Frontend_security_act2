Ciberseguridad & Gestión de Identidad

Portal Seguro Corporativo

Nginx Reverse Proxy • Autenticación OpenLDAP • Rotación de Secrets

🛡️

Arquitectura de Seguridad de 3 Servicios

  • Frontend (Nginx :80): Cero credenciales expuestas al navegador
  • Backend (FastAPI :8000): x-api-key inyectado del lado del servidor + Fernet DB
  • Servicio LDAP (OpenLDAP :389): Autenticación centralizada dc=example,dc=com
  • Rotación de Secrets: Script externo rota secrets de Frontend, Backend y LDAP
